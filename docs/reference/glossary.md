# Glossary

```{glossary}
compute
: The processing power a computer uses to perform tasks. This usually refers to either {term}`CPU` or {term}`RAM`.

CPU
: Central Processing Unit. Executes tasks and processes data.

byte-hour
: A base unit of compute for memory usage. E.g. a server with 4GiB RAM running for 24 hours consumes 4 $\times$ 24 = 96 GiB-hours of memory usage.

CPU-hour
: A unit of compute for CPU usage. E.g. a server with 4 CPUs running for 24 hours consume 4 $\times$ 24 = 96 CPU-hours of CPU usage.

home storage
: Long-term storage. In Linux, every user has a dedicated home folder that lives in a physical storage disk. Any files saved here are available when you log out and log in again. This folder is intended for small files, such as code or text files, and is not an appropriate place to store large datasets.

RAM
: Random Access Memory. Short-term memory that stores working data and machine code.

requests
: For JupyterHubs in the cloud, requests are the amount of {term}`compute` resource a user requests before launching their server.
```
